# ✒️ Novel Generator

AI와 함께 소설·롤플레이를 써 내려가는 **브라우저 단독 실행** 창작 앱입니다.
서버가 필요 없고, 빌드하면 **HTML 파일 하나**가 나옵니다. 데이터는 사용자의 브라우저에만 저장됩니다.

**바로 사용하기** → https://soulfactorx.github.io/novel-generator/
(또는 [Releases](https://github.com/soulfactorx/novel-generator/releases)에서 HTML 파일을 내려받아 브라우저로 열기)

## 기능 (v0.11)
- **AI 제공업체**: Google Gemini · Anthropic Claude · OpenAI 호환(OpenRouter, OpenAI, Ollama 등 로컬 서버). 실시간 스트리밍, 자동 재시도, 중단을 지원합니다.
- **이야기방**: 대화형 이야기 진행. 이야기 설정(세계관·인물)과 장기 기억 메모, 다음 행동 선택지, 다시 생성, 편집·삭제를 지원합니다.
- **📖 소설 자동 집필**: 기획을 적으면 AI가 회차별 개요를 짜고, 한 화씩 또는 끝까지 연속으로 원고를 씁니다. 읽기 화면, 편집, 다시 쓰기를 지원하고 **EPUB·TXT로 내보낼** 수 있습니다.
- **📚 라이브러리**: 세계관(설명·규칙·로어북), 등장인물(프로필·말투·로어북), 주인공을 만들어 여러 이야기에서 재사용합니다. 로어북은 키워드가 대화에 나올 때만 AI에게 전달됩니다.
- **🧠 장기 기억**: 오래된 대화를 줄거리 요약으로 자동 정리해 긴 이야기에서도 앞 내용을 기억합니다.
- **💸 사용량·비용**: 요청별 토큰·예상 비용, 기간·용도·모델별 집계, 월 예산 경고
- **↪ 자동 대체 모델**: 과부하·한도·서버 오류 시 다른 모델로 자동 재시도
- **🩺 이야기 진단 · 🔖 책갈피 · ⑂ 분기**: 캐릭터 붕괴·반복 점검과 지시 반영 다시 생성, 장면 책갈피, 원하는 지점에서 갈래 나누기
- **📲 앱 설치 · 오프라인**: 홈 화면에 설치해 앱처럼 쓰고, 인터넷이 없어도 저장된 글을 볼 수 있습니다.
- **🎨 소설 표지**: AI 그림(Gemini 이미지 모델) · 이미지 올리기 · 글자 표지. EPUB 표지로 들어갑니다.
- **🔄 기기 간 동기화**: GitHub 비공개 Gist로 여러 기기에서 이어 쓰기 (선택적 AES-256 암호화, API 키는 동기화 안 함)
- **글쓰기 설정**: 시점, 분량, 전개 속도, 대사 비중, 창의성
- **콘텐츠 수위**: 전체 이용가(기본) → 성숙 → 성인. 성인 등급은 사용자가 직접 만 19세 이상을 확인해야 선택할 수 있습니다. 어떤 등급에서도 미성년자, 비동의 성적 묘사, 실존 인물은 다루지 않으며, 각 AI 제공업체의 이용 정책이 우선합니다.
- **🎨 화자별 대사 색**: 인물마다 대사를 다른 색으로 보여 줍니다(색·별칭은 라이브러리에서). 입력 없이 [보내기]만 눌러도 이야기가 이어집니다.
- **🧩 프롬프트 관리**: AI에게 보내는 모든 문구(시스템 프롬프트 포함)를 [설정 → 프롬프트]에서 보고 고치고 기본값으로 되돌릴 수 있습니다. 마지막으로 보낸 요청도 확인할 수 있습니다.
- **🗄 저장소 관리**: [설정 → 저장소]에서 사용량·큰 항목을 보고, 쓰이지 않는 이미지·캐시 등을 정리하거나 전체 초기화합니다.
- **데이터**: IndexedDB 저장, JSON 백업·복원, E.No.S Studio 백업 가져오기(이야기·세계관·인물·주인공·소설)
- **🔁 RisuAI 호환**: RisuAI의 캐릭터 카드(**.charx**·**.json**·.png), 모듈(**.risum**), 로어북·채팅 **JSON**을 가져와 등장인물·세계관·로어북·이야기로 씁니다. 첫 메시지(인사말)로 바로 이야기를 시작할 수 있고, 라이브러리의 등장인물은 .charx·.json 카드로, 세계관은 .risum 모듈로 내보내 RisuAI에서 열 수 있습니다.
- **🤖 RisuAI 봇 실행**: CBS 문법·변수, 🎛 토글(언어 선택 등), Lua 트리거·버튼, 블록 트리거, 로어북 규칙, 배경 CSS, 🧭 시작 설정(온보딩)·폼, 배경 그림·🎵 배경 음악·소리·영상, 감정 옆 패널을 RisuAI처럼 실행합니다. [설정 → 글쓰기]에서 기능별로 끌 수 있습니다.
- **📦 패키지**: 가져온 charx는 설정·인사말·이미지·스크립트를 통째로 보관해 언제든 원하는 인사말로 새 이야기·소설을 시작하고, 고쳐 쓰고, 다시 가져와 업데이트하고, 이미지까지 담아 내보낼 수 있습니다.
- **🖼 봇 이미지**: charx 안의 에셋·감정 이미지와 봇의 정규식 스크립트를 함께 가져와, 봇에 정해진 규칙대로(`{{img::이름}}`, `<img="이름">`, `<Emotion="이름">` 등) 이야기와 소설 속에 그림이 나옵니다. 소설 EPUB에도 들어갑니다. 이미지는 이 기기에만 저장되며 동기화·백업 파일에는 포함되지 않습니다.

## API 키와 개인정보
API 키와 이야기는 **이 브라우저 안에만** 저장됩니다. AI 요청은 브라우저에서 각 제공업체로 직접 전송되며, 이 저장소나 다른 서버를 거치지 않습니다.
동기화를 켜면 이야기·소설·라이브러리·설정(API 키 제외)이 **내 GitHub 계정의 비공개 Gist**에 저장됩니다. 동기화 암호를 정하면 브라우저에서 암호화한 뒤 올리므로 GitHub에서도 내용을 볼 수 없습니다.

> 웹 주소로 연 앱과 내려받은 HTML 파일은 브라우저 저장 공간이 서로 다릅니다. 둘 사이에 옮기려면 백업 파일이나 동기화를 사용하세요.

## 개발
```sh
npm ci
npm run dev        # 개발 서버
npm test           # 단위·통합·화면 테스트 (Vitest)
npm run build      # 타입 검사 + dist/index.html (단일 파일)
```
기술: React 19 · TypeScript · Vite · Tailwind CSS v4 · vite-plugin-singlefile

| 경로 | 내용 |
|---|---|
| `src/lib/providers/` | 제공업체별 구현 (Gemini · Claude · OpenAI 호환), 재시도, 모델 목록 |
| `src/lib/prompt.ts` | 시스템 프롬프트·수위 지침 |
| `src/lib/lore.ts` · `memory.ts` | 로어북 매칭 · 장기 기억 정리 |
| `src/lib/novel.ts` · `exporters.ts` | 소설 개요·회차 프롬프트 · TXT/EPUB(내장 ZIP) |
| `src/lib/pricing.ts` · `usage.ts` · `diagnose.ts` | 단가표(기간별) · 사용량 집계 · 진단 |
| `src/lib/risu.ts` · `unzip.ts` | RisuAI 형식 가져오기·내보내기(charx · risum · 카드 JSON/PNG · 로어북 · 채팅) · ZIP 읽기 |
| `src/lib/images.ts` · `imageUrls.ts` | 봇 이미지: 정규식 스크립트 · 에셋 이름 찾기 · 그림 표시 · 안전한 HTML · 프롬프트 |
| `src/lib/sync/` | 동기화: 인코딩·암호화(codec) · 병합(merge) · GitHub Gist 클라이언트 |
| `src/lib/cover.ts` · `pwa.ts` · `public/` | 표지 생성 · 앱 설치/오프라인(manifest·서비스 워커·아이콘) |
| `src/lib/store.ts` | 앱 상태, 저장, 생성 흐름 |
| `src/lib/db.ts` | IndexedDB |
| `src/components/` | 화면 |
| `tests/` | 테스트 |

## 릴리스
1. `package.json`의 `version`을 올리고 `CHANGELOG.md` 맨 위에 `## vX.Y.Z` 항목을 추가해 `main`에 푸시합니다.
2. `git tag vX.Y.Z && git push origin vX.Y.Z`를 실행하거나, Actions → **Release** → Run workflow를 누릅니다.
3. 테스트를 통과하면 GitHub Release(HTML + SHA256SUMS)가 생성되고 GitHub Pages에 배포됩니다.
   Pages는 처음 한 번 **Settings → Pages → Source: GitHub Actions**로 켜 주세요.
